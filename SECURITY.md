# Segurança

Não inclua chaves, tokens, URLs privadas, identificadores de túnel pessoais, perfis ou logs em issues públicas. Relate vulnerabilidades pelo canal privado de advisories do repositório, se disponível; caso contrário, abra uma issue pedindo um canal privado sem publicar detalhes exploráveis.

Este pacote não oferece cofre de credenciais. Configure autenticação pelo host. O painel offline não transmite dados. Instalação e configuração não modificam o launcher, autenticação existente ou projetos. Não há telemetria ou download automático de executáveis.

Revise o código antes de executar scripts. O instalador não é assinado. Windows e o host permanecem responsáveis pelas permissões. Não desative controles globais nem exponha a porta 17841 na internet para fazer esta integração funcionar.
